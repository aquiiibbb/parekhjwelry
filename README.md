# Parekh Jewelers - Landing Page Clone

React + Vite clone of the Parekh Jewelers jewelry care landing page with an animated
falling-diamonds background.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Structure

- `src/components/Header.jsx` — Sticky glass navbar with logo, nav links, cart, sign in
- `src/components/Hero.jsx` — Hero section with headline, subtext, CTA buttons
- `src/components/DiamondField.jsx` — Animated falling diamond SVGs (pure CSS keyframes)
- `src/components/Footer.jsx` — Footer with copyright, legal links, social icons

All styling is plain CSS (no frameworks) — one `.css` file per component.
